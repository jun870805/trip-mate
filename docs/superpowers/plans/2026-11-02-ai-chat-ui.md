# AI 聊天介面 Implementation Plan

> **For agentic workers:** Execute inline, task by task; preserve the existing AI/service boundaries.

**Goal:** 旅程行程頁接上 AI 聊天彈窗、縮小恢復、上傳及寫入預覽，補齊 Firebase 設定與部署說明。

**Architecture:** `src/ai/ui` 是只依賴 React 與通用契約的可複製面板；網站的原生 dialog、CloseButton、Markdown 與旅程欄位差異顯示由 `features/trip-ai` 提供。Provider 延遲初始化；動態 session／data ref 避免舊閉包，旅程／登入改變銷毀 agent。寫後讀取保留彈窗與真實結果，不因 loader 暫時清空 data 而卸載聊天。

**Tech Stack:** React、TypeScript、CSS Modules、原生 dialog、現有 Controller、Playwright。

### Task 1：UI 資料呈現與測試

Files: `frontend/src/ai/ui/presentation.ts`, `frontend/src/ai/tests/presentation.test.ts`, `frontend/src/features/trip-ai/preview.ts`, matching tests。

- [x] 測試隱藏 Function Call／Response、opaque、文件抽取原文；只呈現使用者文字、附件名稱、模型可見文字及真實工具狀態。
- [x] 測試欄位差異／新增／刪除、空值及一般管理者 ID 隱藏。
- [x] 先執行失敗測試再實作純函式，加入既有 AI 測試。

### Task 2：面板與旅程入口

Files: `frontend/src/ai/ui/ChatPanel.tsx`, `.module.css`, `frontend/src/features/trip-ai/TripAIEntry.tsx`, `ChangePreview.tsx`, local CSS, `frontend/src/App.tsx`, shared Icon。

- [x] 聊天記錄、常用問題、輸入與上傳、執行狀態、確認／取消、錯誤／重開對話。
- [x] 懸浮入口僅在行程分頁；dialog header 固定、X／縮小、焦點還原、背景鎖捲動、RWD、安全區與列印隱藏。
