# 每日行程

欄位與閱讀、類別配色、日期／標籤篩選、編輯排序與跨天拖曳。

## 每日行程

### 欄位、內容與閱讀

- 表單：日期、標題必填；時間、副標、內文、標籤與類別選填。標題為多行欄位，內文預留 8 行；標籤為自由文字，以半形逗號 `,` 分隔多個（如 `景點,美食`），顯示時去除前後空白、忽略空值及重複項，各自使用 Badge；保留輸入順序與原始 Sheets 字串。閱讀卡片、詳情及 PDF 一致，多個 Badge 間距 4px，可換行。不顯示排序輸入欄。
- 標籤輸入框右側提供既有標籤選單：取整趟已儲存標籤拆分去重，沿用共用配色；點選追加至末端、逗號分隔、不重複，關閉選單並聚焦輸入框，不自動儲存。保留手動輸入，已選項停用、無資料顯示空狀態；忙碌時停用，不額外讀 Sheets。選單固定 header、選項獨立捲動，避免 header 負 margin 遮擋；長標籤換行，以實際高度定位。支援鍵盤／外部點擊，Escape 只關選單，不觸發外層確認。
- 標籤統一用 `ItineraryTag`，保留 Badge 尺寸／換行，柔和底色配深色字。依整趟行程日期／排序的首次出現順序配色：前五個橘、綠、粉紅、藍、黃綠，色相至少相隔 50 度，之後取最大色相空隙中點。卡片、詳情、PDF、選單共用完整清單，篩選不重配色、末端新增不改前項，不存 localStorage／Sheets。保留強制色彩模式，其他狀態 Badge 不變。
- Sheets 對應：開始時間＝時間、標題＝標題、說明＝副標、內文＝內文、類型＝標籤，新增「類別」獨立欄。舊表可缺內文與類別；Markdown 空白／縮排／換行原樣讀寫，不 trim 內文。
- 舊結束時間、時區、地點、地圖及航班／住宿關聯保留相容，不額外提供欄位；編輯時將舊地點／地圖合併副標，儲存清空已合併來源及舊結束時間，保留關聯與其他未變更值。
- 標題、副標支援實際換行及文字 `\n`，只顯示時轉換，不改 Sheets 原值；網站、詳情與 PDF 一致，內文不做此轉換。
- 副標支援 `[文字](網址)`，用 external 圖示與指定文字；具名 Google Maps 同樣尊重名稱。直接貼網址則 Maps 顯示地圖圖示＋「Google Maps」，其他顯示 external＋「開啟連結」，不吞併前後文字或句尾標點。
- 內文用 react-markdown＋remark-gfm 顯示 Markdown，支援標題、清單、表格、圖片及混合 HTML（如 `<br>`／`<br/>`）。parse5 解析後只輸出允許的排版標籤／屬性，移除 script、style、iframe、SVG、事件、內嵌樣式、來源 id 與危險網址，不用 dangerouslySetInnerHTML；程式碼區塊保留 HTML 原文。連結沿用副標規則，HTML `<a>` 保留文字及外連圖示；外連／圖片只接受 HTTP(S)，無效連結留文字。詳情／PDF 共用，副標不啟用 HTML。
- 內文支援 `[跳到交通方式](#交通方式)` 對應 `## 交通方式` 等 h1～h6（含 HTML 標題）。自動產生該份內文專用定位 ID：英文小寫、空白轉 `-`、忽略標點，同名依序加 `-1`、`-2`；不直接採用來源 HTML id。
- 段落連結沿用底線文字連結、不加外連圖示或開新分頁；點擊只捲動目前 dialog 並避開固定 header，焦點移至目標但不改網址／路由、不捲背景。遵循減少動態效果設定；找不到該內文標題的片段連結只顯示文字，不跳到其他內文或頁面。副標不開放段落跳轉，PDF 保留同份內文的定位連結及標題。
- 閱讀卡片／PDF 標題與標籤頂端對齊（`align-items: flex-start`），標籤靠右上、最多佔內容一半，不受長標題擠壓；標題可縮及換行，多標籤可換列、長標籤可換行。文字不得超出內距或裁切，不改全站 Badge。
- 時間字級 14px、欄寬 44px，與內容卡片間距 8px，對整張卡片垂直置中；編輯清單另有緊湊規格。
- 副標與「查看更多」同一列，距主標 4px，`align-items: flex-end`；副標左側可換行，按鈕不壓縮、靠右與底部對齊。僅非空白內文顯示無圖示底線文字按鈕；無副標仍靠右。
- 有非空白內文的閱讀卡片可整張點擊開啟詳情，透過既有「查看更多」按鈕延伸點擊範圍，保留鍵盤操作及 aria-haspopup；副標內連結優先操作，不誤開詳情。無內文不啟用卡片點擊，PDF 不列印操作覆蓋層。
- 詳情 dialog 依序標題、副標、tag、內文；header `align-items: flex-start`，X 靠右上對齊標題。固定 header／12px 下距及外層 24px／20px 沿用全站規格；第一內容不疊加 margin，內文上距 12px，以 8px padding 的 panel 包裹。保留 X、Escape 與焦點管理。
- 詳情捲動且 scrollTop > 0 時，右下顯示「回到最上面」圖示按鈕；每次捲動重設 3 秒倒數，靜止到時或到頂即隱藏，關閉／卸載清計時器及狀態。按鈕固定在 dialog 可見區、沿用 RWD 內距，不佔高度或捲背景；返回後焦點移至 header X，不關閉，遵循減少動態效果。

### 行程類別與卡片配色

- 獨立單選「類別」：未分類、三餐、活動、交通、購物，來源 `frontend/src/data/itinerary-categories.json`；三餐不細分，與自由標籤／篩選分開。
- 類別缺欄／空白視為未分類，不由標籤推測；沿用選填欄位補欄、保留原資料及範本同步規則，手動維護也使用固定選項。
- 閱讀卡片以柔和低飽和底色及較明顯的同色系細邊框區分類別：三餐橘、活動綠、交通藍、購物粉；未分類沿用一般米白卡片。移除類別 icon／浮水印，保留 sr-only 類別文字；強制色彩模式使用系統顏色。
- PDF 共用類別配色，不改內容位置；詳情／編輯清單不套用。不新增帳務連動或分類推導，複製／排序保留類別。

### 日期與標籤篩選

- 日期為旅程期間每天的完整選單、早到晚排序，包含空白日，保留全部日期；舊超出範圍資料仍可見供修正。閱讀初開時若旅程期間的目的地今天有行程則選今天，否則全部。
- 日期旁有標籤選單，預設「全部標籤」，列整趟各日期所有非空標籤、去重且保留首次順序；不隨選定日期縮減。篩選仍一次選一個標籤，活動只要包含該完整標籤即符合（不以子字串比對），與日期共同篩選；選項拆分並去重，無標籤僅在全部標籤顯示，已選標籤消失則回全部。
- 全日期篩選隱藏無符合項目的日區塊；單日無符合項目顯示空結果。控制項距 8px、窄螢幕換行，不增加可見標題／提示。
- 每日日期依旅程開始日編號，開始為第 1 天，按日曆日期差計算，篩選不重編號；旅程起訖範圍外的日期只顯日期，不顯示 DAY／D 天數（不產生 D0、負數或結束後天數）。旅程起迄與該日期同一年時省略年、月日不補零、星期用半形括號且無額外空白（如 `4/13(一)`）；跨年旅程及異年度舊資料保留 `YYYY/M/D(一)`。整趟旅程標題／日期區間仍顯完整年份，不更動 ISO 值。
- 行程總覽（含 PDF）保留原本特別大的奶茶棕 `DAY 1`，旁邊日期與星期維持 13px 正常灰字、不加 `-`，日期與星期之間加一個半形空格，例如 `4/13 (一)`。編輯行程的每日分組、編輯日期篩選、每日行程新增／編輯日期選單，以及總覽日期篩選，統一顯示 `D1 - 4/13(一)`，保留「全部日期」選項。

### 編輯、排序與跨天拖曳

- 每日行程、航班、住宿編輯清單在編輯／刪除左側提供「複製」：直接儲存，從最新驗證快照自動產生新 ID，不手填；其餘原始欄位（時間、日期、時區、排序、標籤、類別、內文空白、關聯、額外欄等）完全保留。追加列、不重排或改原筆、不複製關聯資料。一般管理者依 Google ACL 操作，沿用快照／批次寫入／結果不明重讀規則；忙碌、拖曳、衝突確認時停用。帳務／進度不提供複製。
- 每次開啟編輯行程，預設「全部日期」，依天分組並保留空白日作放置區；單日新增沿用選定日，全部日期新增須選實際日期，不寫入 `all`。
- 新增有時間依時間插入，相同時間接在既有同時段後；無時間放當日最後。改日期／時間重新插入，只改其他內容保留位置；排序以 10、20…持久化。
- 手機與電腦都只有拖曳圖示啟動排序，保留把手方向鍵操作；卡片其他區域正常捲動 dialog。pointer capture、preventDefault、touch-action:none 僅用在把手。
- 卡片跟隨滑鼠／手指，預覽放置位置、靠近 dialog 邊緣自動捲動；放開且位置／日期改變才儲存。全部日期可跨天及移至空白日，目的日期須在旅程範圍內，同批更新該日期及來源／目的日排序。
- 與目的日相鄰有時間項目的先後衝突時，先確認移除被移動那筆的開始／舊結束時間，保留其他活動時間；取消不寫入並恢復。提供按部署 base 存 localStorage 的「不再提醒」，失敗須提示；已勾選則同類衝突直接清時間再排序。
- 忙碌／衝突確認時停用排序，拖曳中避免編輯／刪除；pointercancel、失去 capture、篩選／資料改變、resize、失焦、隱藏或卸載時取消未完成手勢，不寫入、不留草稿。
- 編輯卡片僅時間與標題、不顯示副標／內文／tag，單行超出省略；時間保留完整。內距 8px、gap 4px、內容最小高 28px、行高 1.4；把手按含操作區的完整卡片高度置中，小螢幕橫跨兩列。
- 自由標籤寫入時，同批只清除有變更且非空標籤儲存格的舊固定選項驗證，不清其他驗證與格式。
