# AI 助手：郵件、錯誤回報與回覆評價

訪客郵件、錯誤回報、回覆評價及對話暫存保存／驗證。

## 郵件、錯誤回報與回覆評價

- 訪客行程需求轉寄已採用 EmailJS：未登入且正式旅程可整理調整需求，預覽正規化後 `VITE_GUIDE_EMAILS` 第一筆收件人、主旨及完整本文，使用者按「確認寄送」才送出。訪客只有獨立 `contact_guide` 權限，不取得 Sheets 寫入權。已登入／範例／設定不完整不提供寄送工具；批准前重新確認身份與公開旅程可用。郵件不包含原始附件、整段聊天或憑證，稱呼／回覆信箱僅使用自願提供資訊。EmailJS `title` 帶入旅程名稱，`name` 帶入使用者明確提供的姓名，未提供為「未知使用者」；`time` 為確認寄送當下台灣時間（Asia/Taipei、`YYYY/MM/DD HH:mm:ss`）；保留原有 `trip_name`／`requester_name` 參數相容範本。
- 郵件工具與 EmailJS adapter 位於 `features/trip-ai/guest-email.ts`、`emailjs.ts`，不放入可移植核心。環境變數 `VITE_EMAILJS_ENABLED/SERVICE_ID/TEMPLATE_ID/PUBLIC_KEY` 為公開設定；無私鑰。EmailJS 範本 To 必須固定第一位導遊，不能使用前端動態收件人；此遠端設定無法由純前端獨立驗證。設定步驟與限制見 `docs/setup-email.md`。
- 寄送獨立確認，不把聊天中的同意當成已寄出。聊天已同意或明確要求寄送且需求足夠時，直接準備郵件預覽，不重複口頭詢問；選填姓名／回覆信箱不得強制追問。寄送成功或取消後以應用的工具結果結束該輪，不再呼叫模型追問或重新提出寄信；之後使用者仍可提出新的需求。取消／重整不寄送；寄送中禁止關閉／新對話，重複批准不重送，失敗／未知結果不自動重試。成功僅表示 EmailJS 接受寄送申請，不能宣稱已收件或已修改行程。保留單一 agent 的 60 秒冷卻、15 秒請求逾時；前端限制不能取代服務端防濫用。尚未執行真實郵件投遞。
- AI Provider 請求失敗會於既有提示後顯示「(錯誤代碼：code，錯誤訊息:message)」，代碼優先 HTTP status，再取 SDK code，無資訊為 unknown；僅保留經憑證遮蔽及長度限制的錯誤文字，不顯示／傳送 headers、SDK 物件、opaque 或原始附件。錯誤後方以空格接「回報錯誤」文字按鈕，使用者點擊才透過既有 EmailJS 範本固定 To 回報第一位導遊，name／requester_name 為「錯誤回報」，title 沿用旅程名稱，包含最後一則使用者原始文字（最多 6000 字且遮蔽憑證）、模型、API 路徑、錯誤代碼／訊息、旅程、頁面無查詢參數網址、台灣時間及回報編號。同筆錯誤只能提交一次，失敗／未知結果不自動重送；只有 EmailJS 200／OK 後顯示原生彈窗「回報成功」及「謝謝您的回報，我們將儘速修正錯誤」。EmailJS 未設定時停用按鈕並顯示未啟用；此回報獨立於訪客行程調整工具，登入導遊也可回報，沒有行程寫入或模型再次詢問。診斷僅保留在當次狀態，不存入已完成對話暫存。
- 每則完整且非空白 AI 訊息的複製按鈕右側依序顯示 14px 無邊框讚／倒讚，提示與無障礙名稱為「回應良好」「回應不佳」。讚與倒讚互斥選取，選取的圖示填滿奶茶棕，再點同一按鈕取消；不加 hover 或選取底色，按鈕背景保持透明，選取只以圖示填色表示，沿用正常焦點行為；讚僅切換當次元件選取狀態，不寄信；倒讚由使用者點擊後直接沿用 EmailJS 固定第一位導遊範本寄送，title／subject 固定「AI回覆不佳回報」，name／requester_name 為「回覆不佳回報」，包含該則可見回覆、其前最近一則真正使用者問題、模型、旅程、頁面與台灣時間。不附整段對話、附件、工具參數、opaque 或憑證；問題最多 3000 字、回答最多 6000 字，並遮蔽憑證。郵件提交與評價選取狀態分開：取消或切換評價不撤回／中止已開始的寄送，再選倒讚也不重寄同一元件的回報；200／OK 才彈窗「感謝您的反饋！」，失敗／未知結果不自動重送或顯示成功。未設定 EmailJS／收件人時倒讚停用、讚仍可用；串流未完成不顯示評價。狀態僅保留當次元件記憶體，不存入對話或還原執行，切換模型／重新整理可重建。

## 保存與驗證

- 已完成且無附件的對話，包含配對工具結果及 Provider opaque 簽章，以 sessionStorage 按部署 base、來源、旅程／Spreadsheet、身份、Firebase 設定與模型隔離。重新整理後開啟助手可恢復；不還原權限或執行工具。版本／格式／配對錯誤或超過 80 則／1 MiB 不恢復；暫存失敗回退記憶體並提示。附件對話全段僅保留當次，介面明示；寫入中／錯誤時移除暫存，避免還原結果不明的紀錄。登入身份變更清除離開身份的暫存，登入還原不誤刪驗證中的身份紀錄。
- 實際接入與驗證見 `docs/ai-agent-integration.md`；真實模型／App Check／Google 寫入仍須外部設定與實測，不能以測試替身宣稱正式服務驗證完成。
