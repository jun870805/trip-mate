# 航班、住宿與 PDF 匯出

航班／住宿版型與資訊，以及 PDF 匯出。

## 航班與住宿

### 共用版型與資訊列

- 桌面（701px 起）與 PDF 左航班、右住宿，各區卡片單欄依序往下；手機先航班再住宿。桌面欄距 18px、PDF 12px、手機區塊間距 24px。卡片自動高度、頂端對齊，不拉成同高。
- 每筆預訂各一張米白細邊框卡片，內距見 [ui-and-dates.md](ui-and-dates.md#尺寸與間距) 的尺寸表。避免標題與後卡分頁、卡片頁內拆分；不用舊 `.two-column` 列印規則。
- 航班行李／備註與住宿入住／退房／地址／電話／價格／備註共用 `.booking-details`：灰色標題 12px、內容 13px、行高 19.2px、欄距 8px、列距 4px、群組上距 12px。
- 標題對齊內容第一行垂直中心，內容換行縮排至內容起點、保留手動換行；標題上 padding 0.05px。未填選填資訊不顯示，不對齊整段內容中心。

### 航班

- 卡片第一列左出發日期、右「航空公司 航班編號」，相同字體、不加徽章；與下方機場資訊相隔 12px。
- 機場、航廈、時間各佔一行；兩側各自維護出發／抵達航廈，顯示灰色小字、不加航廈標題。任一側有航廈時兩側保留該行，兩側皆空才移除，但機場與時間仍換行。
- 航班時間畫面 22px、列印 16pt。抵達與出發當地日期不同時，在抵達時分後標日曆日差 `(+1)`／`(+2)`／`(-1)`，同日不標；不換算時區或推算飛行時長。
- 舊單一航廈欄保留，兩側新欄皆空時作「既有航廈資訊」提示，不推測歸屬；編輯提示分開填寫，儲存時補兩新欄。
- 按出發當地日期＋出發機場＋抵達機場分組；機場僅忽略大小寫、前後及連續空白，不推測城市等價。保留原資料順序，去回／異日／轉機前後航段不混組。
- 同組不同班次各保留完整卡片，螢幕一次一張；卡片內底部置中左箭頭、`1/2` 頁碼、右箭頭。首尾停用對應方向、不循環；單筆無切換器，各組獨立、不保存偏好。PDF 印全部卡片、隱藏切換器。

### 住宿

- 飯店名稱畫面 20px、列印 15pt、行高 1.4，可自然換行；副標題獨立欄位，14px 灰字、距名稱 4px，未填不留空列，不自動搬移原備註。
- 左側名稱、副標與資訊，右側保留固定比例圖片區；圖片僅 HTTP(S)，缺少、無效或載入失敗留空，不放示意圖或提示。手機與 PDF 同樣保留圖片位置。
- 入住／退房各一行靠左，顯示日期與選填時間；日期必填且退房晚於入住。當地時間可空，不推測或預填 15:00／12:00。
- 地址、電話、價格帶欄位標題；電話可撥號。價格為自由文字，不自動記入帳務；備註放價格下面，無價格則放其他入住資訊後，與航班備註同樣式。
- 地圖與訂房網站在同列，列上距 8px、連結間隔 12px，窄螢幕可換行。訂房網站使用房子圖示；Google Maps 可顯示網址內地點名稱，無名稱短網址顯示 Google Maps，非 Google 地圖顯示「開啟地圖」。圖文連結規格見 [ui-and-dates.md](ui-and-dates.md#共用元件與表單) 的共用元件。

## PDF 匯出

- 入口為單一匯出 icon，保留「匯出 PDF」無障礙名稱／提示；先開日期選擇 dialog，不在頁面常駐匯出設定。
- 可勾任意一個或多個行程日，提供全選與「匯出所選日期的每日行程，以及全部航班與住宿；列印時選另存為 PDF」提示。正在看單日則預選該日，否則全部；有行程至少選一日，無每日行程仍可印預訂資訊。
- 確認先套用列印日期並關閉 dialog，再開瀏覽器列印；不改閱讀篩選。列印所選日期的全部標籤行程、所有班次與住宿、地圖／訂房連結；不含帳務、待辦、導覽、編輯操作或分頁切換器。
- 內文直接在 PDF 展開 Markdown，不印查看更多按鈕／詳情 dialog。日期標題保留 DAY 編號。
- PDF 保留旅程名稱、目的地、日期、匯率與時差，部分日期另列匯出範圍；與網站共用 TripMetadata／TripFacts 的樣式。標題資訊與預訂區間距 12px，不重疊額外 padding／margin。
