# AI 助手：聊天介面與操作

聊天入口、視窗行為、訊息輸入與顯示。

## 聊天介面與操作

- 已確認介面：右下方明顯機器人入口，按鈕文字固定「AI 助手」，不因已有對話改為「繼續對話」；701px 起為從視窗最上方延伸到底部的右側非模態聊天欄（包含 Logo／header 的高度），左側讓出寬度且可繼續操作、捲動與展開行程內文。700px 以下為聊天視窗，以 modal 語意、inert、焦點循環及共用背景捲動鎖限制背景互動。沿用全站配色、字體及手機底部導覽安全區。
- 入口依原規劃僅在有效旅程的「行程」分頁；正式旅程訪客唯讀、導遊依 ACL 寫入，範例唯讀且限導遊。首頁、其他旅程分頁、載入失敗或行程資料損壞時不顯示入口。
- 視窗標題「AI 助手」，下方旅程名稱固定單行、過長以省略號顯示，保留完整 title 提示；機器人採圓臉笑容圖示。右上使用共用無邊框 X 關閉按鈕，行為維持縮小；Escape 同樣縮小並保留當次記憶體對話、附件、輸入與待確認預覽，跨尺寸保留同一元件。X 左側顯示有邊框「新對話」文字按鈕（無障礙名稱與提示為「新對話」）；點擊清除當前對話、上下文、輸入、附件、未提交預覽及暫存並開始新對話，不撤銷已儲存行程。未來另有歷史紀錄按鈕，本次尚不實作。寫入中禁止關閉／清空。切換旅程、登入身份、離開行程分頁或外部重讀會清理舊 agent 與待確認操作；本次 AI 寫後重讀保留對話及真實結果。
- 空白聊天大字標題為「您好！ 我是您的 AI 助手」，就緒後說明為「輸入提示詞即可開始使用，或是可以先試試以下功能～」。模板提示詞點擊立即送出，不需再次按送出；沿用忙碌／權限限制並防止重複送出，不自動夾帶未送出附件。
- 桌面（701px 起）訊息 Enter 送出、Shift＋Enter 換行；手機（700px 以下）Enter 換行，使用送出按鈕送出，中文輸入法組字／選字 Enter 不送出，原有 Ctrl／Command＋Enter 送出仍保留。
- 每則非空 AI 回覆下方最左側提供小型無邊框複製圖示，複製該則已呈現回覆的文字原文（Markdown 保留原格式），不包含角色、工具原始資料或附件；成功短暫顯示勾號，失敗提示手動選取。
- AI 請求處理中依實際階段顯示「思考中...」「正在回覆…」或工具對應的易讀步驟（查詢／搜尋行程、準備變更／郵件預覽等），搭配「(x秒)」及旋轉 loading，滿 60 秒改為「(x分x秒)」；每輪思考從 0 秒開始，以實際經過時間每秒更新，切回分頁校正，結束／錯誤／待確認／卸載停止計時，不將計時持久化，減少動態效果時停用旋轉。訊息不顯示「你」「AI 助手」角色名稱，輸入框不顯示「訊息 *」，仍保留隱藏的無障礙名稱；輸入框 placeholder 為「問問 AI助手」，文字視覺大小桌面／手機皆為 14px；手機（700px 以下）以計算字級 16px 搭配 0.875 縮放及寬高補償，避免 iPhone Safari 聚焦自動放大，保留瀏覽器手動縮放；手機輸入框固定高度並保留內部捲動，輸入區上方 padding 為 12px，待上傳附件的移除按鈕 padding 為 1px。工具實際操作結果仍保留標示。
- 聊天不顯示檔案格式／數量／大小說明、一般「本分頁暫存」及閒置「唯讀查詢」等描述；仍保留檔案驗證、處理中／待確認狀態及暫存失敗／附件不保存的必要提示。
- 模型回覆以安全 Markdown 顯示，不自動載入模型指定的遠端圖片。聊天不顯示文件抽取原文、工具參數、原始結果或 opaque 資料；一般角色隱藏業務 ID，確認預覽逐筆顯示操作、日期、欄位前後差異與警告；不顯示內部「排序」欄位，仍保留實際排序操作。數量提示為「共 N 筆受影響項目。」；刪除時緊接同一段顯示「包含刪除操作，儲存後無法復原。」（正紅色 #ff0000），兩者不另起行，窄螢幕可自然換行。
