# 全站視覺、UI 與日期時間

全站視覺與文案、尺寸、共用元件、dialog 捲動、CSS 管理，以及日期／時間與旅程標題資訊。

## 全站視覺與文案

- 簡單明瞭、柔和低飽和、適中留白，以易讀及手機 RWD 為優先。專案已確認的設計規則優先於通用設計技能或元件庫預設。
- 米色底、奶茶棕主色、低飽和橘對比色；卡片使用淺米白、細邊框，圓角以 4px／8px 為主。沿用既有 CSS 變數，不另建一套配色。
- 全站優先使用 Chiron GoRound TC（昭源環方），由 Google Fonts 載入 200～900 可變字重；載入期間或失敗時依序使用 Microsoft JhengHei、PingFang TC、system-ui、sans-serif 備援。
- 文案只表達功能、實際資料、操作及狀態；不加入口號、情懷、品牌故事、裝飾性標題或無資訊用途的大型開場區塊。同一訊息不反覆出現在標題、副標與頁尾。
- 操作、幣別、帳務、時區與錯誤提示可保留，但須簡短。以間距區分內容，減少 divider、巢狀框線；不以陰影取代分隔線。保留輸入框、主要卡片、按鈕與導覽選取狀態的必要邊界。

### 尺寸與間距

| 項目 | 現行規格 |
| --- | --- |
| 小範圍間距 | 以 8px／12px 為主，分區仍保留適中留白 |
| 網站最上方標題列 | 上下 padding 18px |
| 主要按鈕 `.button` | 上下 8px、左右 12px |
| 輸入框／下拉選單 | 沿用上下 6px、左右 10px 的緊湊規格及既有 RWD 覆寫 |
| 單選下拉箭頭 | 距右邊框 12px；文字右側預留 40px；奶茶棕箭頭 |
| 一般卡片 padding | 電腦 16px；手機（700px 以下）12px；PDF 16px |
| dialog 內卡片 padding | 電腦、手機皆 8px；只覆寫 dialog 範圍 |
| 編輯／行程詳情 dialog 外層內容 padding | 電腦 24px；手機 20px；不可與內層卡片 8px 混淆 |
| 一般 dialog 標題與內容 | 間距 12px，避免 margin 與 gap 重複相加 |
| 航班／住宿／每日行程編輯卡片 | 細邊框、8px 圓角；卡片間距 8px |

- 共用卡片使用 `--card-padding`，`.catalog-dialog` 範圍覆寫為 8px。局部編輯需求不得改動閱讀畫面或 PDF 共用樣式。
- 手機旅程選單固定螢幕底部，不隨捲動方向隱藏，保留安全區；沿用既有不透明米白底與繪製層，不用背景模糊。Safari 實機待驗問題列於 [pending.md](pending.md)，不把已撤回的優化重新加入。
- 首頁「選擇旅程／重新整理」及旅程上方「所有旅程／重新整理」工具列目前暫時隱藏，連佔位間距一起隱藏，保留元件以便恢復。首頁導遊的「新增旅程」靠右保留；搜尋、狀態篩選、錯誤畫面的返回／重試仍保留。不顯示更新時間。

### 共用元件與表單

- 圖示＋文字超連結統一用 `IconTextLink`：奶茶棕、12px／400 字重文字、14px 圖示，左右排列、圖文間距 2px；多個網站連結間距 12px。不得各自覆寫字級、顏色或重新拼 SVG＋anchor。
- 外連只接受 HTTP(S)，另開分頁並加 `noopener noreferrer`；站內連結沿用部署 base、同頁導覽。卡片整體連結及導覽保留原元件。
- 右上角關閉統一使用 `CloseButton` 的 X 圖示，保留無障礙名稱、提示、鍵盤操作及忙碌時限制；底部取消／確認保留文字。
- 必填欄位名稱加 `*`；條件必填隨狀態標示，不能為簡化介面而移除驗證。
- 日期、資料類型、團員、旅程搜尋／狀態、標籤等篩選不顯示多餘標題，保留 sr-only／aria 名稱。下拉選單不額外加入提示、副標或無用途的佔位選項；編輯表單欄位名稱及「未指定」等業務空值仍保留。

### dialog 與捲動

- 任一 dialog 開啟時背景不可捲動，只允許當前 dialog 及其內部區域捲動；抵達邊界不將捲動傳到背景。涵蓋編輯、詳情、PDF、日期／時間及巢狀確認。
- 使用共用開關監聽；最後一層關閉或移除後才解鎖，恢復原頁面位置與樣式。固定 body 並補償捲軸寬度，不封鎖 dialog 內觸控、時間滾輪及拖曳自動捲動；列印不沿用固定 body。
- 所有原生 dialog 使用共用 sticky header：標題／X 固定頂端、米白不透明底，保留 RWD 內距，不加 divider／陰影。標題下方 12px 留白放在 header 內部 padding，不用外部 margin／gap，第一個內容不疊加上距；詳情同規則，日期彈窗頂部年月列也須固定。
- 旅程內「編輯行程」「編輯帳務」「編輯進度」統一關閉確認：只要開啟新增／編輯表單，按 X 或 Escape 即提示「尚未儲存的內容不會保存，確定要關閉嗎？」（即使未改值也提示）。取消保留當次輸入，確認才捨棄表單並返回同一彈窗的上一層列表，不關閉整個彈窗、不寫雲端，保留資料類型及日期篩選；儲存中禁止返回或關閉，列表層的 X／Escape 直接關閉整個彈窗。表單底部取消仍返回清單，不加入草稿或 beforeunload；旅程目錄編輯不在此規則範圍。
- 行程時間衝突 dialog 寬 `min(460px, calc(100% - 32px))`、內容填滿；沿用共用固定 header／12px 留白，內容分組距 12px，第一組不疊加上距。

### CSS 管理

- `index.css` 管理 Tailwind 入口、變數、基礎元素與全站行為；`styles/` 按 shared、layout、catalog、trip-views、editors 分工。
- 元件局部樣式使用同層 `.module.css`，透過匯入的樣式物件引用；共用樣式集中維護，不強制一個 TSX 配一個 CSS。
- 航班／住宿閱讀與編輯共用 `BookingCards.module.css`；局部需求限制在對應元件範圍。
- `index.css` 的基礎 `.muted` 會在樣式匯入後定義；局部字級須用明確元件 selector 避免被覆蓋（如 `.ledger-summary.muted`），不要為局部需求改全站 `.muted`。
- `main.tsx` 先匯入全域 CSS 再匯入 App；必要時明確用 `:global(...)` 連接共用類名，不擴散局部規則。保留列印、減少動態效果、強制色彩及鍵盤操作樣式。

## 日期、時間與旅程標題資訊

- 閱讀畫面、清單與 PDF 日期預設使用 `YYYY/MM/DD`；每日行程的緊湊日期格式依 [itinerary.md](itinerary.md) 的「日期與標籤篩選」。日期／時間區間及項目分隔使用半形 `-`。內部值、Sheets 與排序仍用 ISO，不因格式化換算時區。
- 全站使用 24 小時制 `HH:mm`，有效範圍 `00:00`～`23:59`。主輸入框支援 `9:30` 自動補為 `09:30`；保留未完成的 `9:`／`9:3`，無效值不轉成其他有效時間。
- 航班填各出發／抵達地當地日期時間，住宿及每日行程填當地時間，不輸入 UTC 偏移、不推測機場時區。新航班儲存無偏移時間，每日行程時區留空；舊含偏移／時區資料相容且未修改時保留原值。
- 不直接比較兩地航班鐘面時間先後；僅兩端皆為舊明確偏移格式時可核對實際先後。不推算飛行時長。
- 使用共用自訂日期／時間 UI：主欄位可打字，按鈕開選擇器；支援 Alt+向下／F4、Escape、清除與取消。日期輸入接受斜線及 ISO，顯示斜線，儲存前驗證。
- 選擇器只定位、不自動預填：已有值優先；空白結束／退房／抵達優先定位對應開始／入住／出發，再回退旅程開始日。行前費用例外，定位到台灣今天。每日行程選定單日後新增可沿用該日。
- 編輯帳務的「新增公積金交易」「新增行前費用」「新增收款批次」例外：開啟新增表單時，日期／收款日期預填台灣當日（Asia/Taipei）。僅初始預設，使用者可改選或清空，不隨開啟選擇器、切月份或跨日自動補回；編輯既有資料保留原日期，未儲存不寫入雲端。
- 開啟、切月份、取消、關閉及待辦切已完成都不自動填日期／時間。日曆可點年月選月份、年份及年區間，實際選日才填值。
- 時間彈窗只有小時 `00`～`23`、分鐘 `00`～`59` 垂直滾輪，支援滑鼠、觸控、點選、方向鍵／Home／End；確認才寫入，取消保留值。主輸入框仍可打字。
- 一般日期選擇器不額外限制旅程範圍，沿用各業務驗證；每日行程例外，只能新增／儲存旅程範圍內日期。
- 日期選擇器固定年月列的 `margin-bottom` 使用 `-8px`，避免遮住星期文字；上方與左右負邊距維持 `-12px`。
- 旅程時區支援 IANA 或固定 `UTC+9`、`UTC-5`、`UTC+05:30`、`UTC+05:45`、`UTC`；正規化為 `UTC±HH:mm`／`UTC`，範圍 UTC-12:00～UTC+14:00。固定時差不隨夏令時間變動；建檔屬性用對應 `GMT±HH:mm`。
- 旅程名稱與狀態 tag 垂直置中。下方目的地與日期區間前有圖示，兩者水平間距 16px；資訊列垂直間距 8px。
- 再下一列顯示圖示＋「匯率：1 TWD = 數值 當地幣別」及圖示＋「時差：+0 小時／+1 小時／-13 小時」，窄螢幕自然換行。不顯示兩地即時鐘或技術性時區名稱。
- 時差＝目的地減台灣，台灣固定 Asia/Taipei，依當下 IANA／夏令時間計算，不以 24 小時取模；保留半小時／45 分鐘時區的小數。定期及切回視窗時重算，不額外讀 Sheets。
