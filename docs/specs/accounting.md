# 帳務業務規則

公積金、行前費用、收款批次與支出閱讀／參考金額。

## 帳務業務規則

### 共用排序、統計卡片與編輯列表

- 團員新增／編輯不顯示「排序」欄位；團員清單、帳務／關聯選單及閱讀／PDF 依 ID 數字由低到高排序（M999 在 M1000 前）。保留舊 Sheets 排序欄及原值，不移動資料列或改動帳務金額。
- 公積金與支出頁面上方統計卡片的 gap，以及統計區塊到下一張卡片的距離，桌面 12px、手機（700px 以下）8px。由統計區塊 margin-bottom 控制，緊接的公積金對帳／所有費用卡片 margin-top 為 0，不影響其他頁面。
- 編輯帳務的公積金交易、行前費用、收款批次分別依日期／收款日期由早到晚分組，同日維持原順序；團員不依日期分組。日期標題在卡片外，沿用編輯行程的 `D1 - 4/22(三)`、13px 灰字、下方間距 8px；僅旅程範圍內顯示天數，範圍外顯示完整年月日與星期（如 `2027/4/1(四)`）。
- 每日帳務項目使用共用 panel：米白底、1px 細邊框、8px 圓角、dialog 內距 8px；同日項目 gap 12px，1px `--line` 分隔線置於間距中央，單筆不加線；不同日期區塊 gap 24px。
- 每筆編輯列表資料第一行為項目（收款批次為團員名稱），第二行為類型與總金額、間距 12px，不重複日期；編輯／刪除操作保留。
- 手動個人金額欄（調整、既有行前費用等）保留姓名與無障礙名稱，不額外顯示「金額」標題。只接受數字及單一前置 `-`，輸入中可空白／單獨負號，儲存須完整數字；拒絕小數點、千分位、指數、空白及其他字元，不自動刪字變成另一金額。不改其他金額欄與既有 Sheets 小數解析。

### 公積金記帳

- 每趟獨立收款、支出與退款，團員各有餘額，不跨旅程沿用。只收退當地貨幣，不收台幣、不以匯率換匯入帳。
- 實際參與者同額向上取至幣別最小單位，未參與不扣。例如 1,000 JPY 三人各扣 334，合計 1,002；實際支出仍為 1,000，尾差 2 成公共餘款，不分給特定團員。
- 公共餘款保留待決定用途，不自動退款或另列消費。對帳須滿足「個人餘額合計＋公共餘款＝現金餘額」；結束標示待退／待補／已結清，負餘額提示待補、不顯示可退。
- 支出一次輸入項目、實際金額與參與者，同步建立交易、分攤及支出總表，刪除同步移除。分類為必填下拉：交通、餐飲、住宿、活動、小費、其他，預設其他；編輯既有清單外分類時保留原選項與值。
- 收款／退款各輸入一個「每人收款金額／每人退款金額」（當地幣別、正整數），下方只勾團員，依人數加總。調整仍逐人填正負金額並加總，且須理由。
- 支出／收款／退款的參與者可同排多個、自然換行，提供全選與逐一取消；已全選、無團員、儲存中停用全選。全選不儲存、不修改既有逐人金額；調整保留手動金額流程。
- 介面「收款」對應 Sheets／計算層的既有代碼「儲值」，不遷移雲端資料。舊收款／退款若金額不同，共同欄留空並提示保留原值，原金額唯讀；可保留／刪減原參與者，新增參與者須填共同金額，只有明確填入後才統一套用。

### 公積金閱讀畫面

- 團員餘額卡片保留姓名、餘額，不顯示「目前可退餘額」；負餘額在金額後接「（待補繳）」。手機卡片 gap 8px，姓名與右側金額以 Grid 垂直置中、不用 float。
- 收支明細依日期由早到晚分組，同日維持原順序；團員篩選後只顯示該團員有參與的交易及符合交易的日期。標題沿用行程閱讀畫面的 `DAY N`＋`M/D (星期)`，跨年保留年份；範圍外不顯示 DAY，日期不逐筆重複。
- 收支明細標題與右側團員下拉選單以 `align-items: center` 垂直置中，電腦、手機一致。標題列 margin 0、padding-top 24px、padding-bottom 0；均分說明下方 margin 16px、padding-bottom 0。日期區塊各自 margin／padding 0，以容器 gap 16px 分隔；日期到下方交易卡片 12px。
- 同日交易間距使用 `--ledger-gap: 16px`，電腦、手機一致，不加每筆之間的分隔線；此變數僅作用於公積金收支明細，不影響其他頁面、編輯列表或不同日期區塊間距。交易標題 16px、金額 14px，桌面與手機一致。
- 每筆交易預設收合，第一行保留類型、項目、金額與右側向下展開圖示；點擊或鍵盤操作可獨立展開／收合下方內容，展開時箭頭朝上，不持久保存展開狀態。
- 選「所有團員」時，第一行顯示實際交易總額。展開後，同額分攤合併為「每人 幣別 金額，參與人員：姓名、姓名…」，姓名自然換行；不同額的歷史資料仍逐人列出。「分攤合計、公共餘款增加」只在該筆公共餘款增加不為 0 時顯示，放在團員明細上方，12px、margin-top 4px、區塊顯示；為 0 隱藏整行、保留團員明細。
- 選定團員時，第一行改顯示該團員實際分攤金額；展開後以「x 人參與，總共 xxx」取代原本分攤／參與人員說明及公共餘款說明。人數以該筆完整分攤資料的不同團員計算，總共為實際交易總額；支出因向上取整使分攤合計超過實際支出時，後接「(向上取整後 xxx)」，括號內金額為全體分攤合計，無尾差不顯示。所有金額保留幣別及正負號，不改寫帳務資料。
- 團員分攤資訊為 12px、padding-top 8px、margin 0，下方無額外留白；金額不加額外 margin-left，保留文字本身的空格。

### 行前費用與收款批次

- 行前一律使用實際刷卡台幣金額並收台幣，不套用匯率。到店住宿等公積金支出不列為行前待收款；公積金費用須關聯支出明細，不重複計算，收款與退款不是旅遊消費。
- 新增行前費用只勾選「實際參與者」、可全選，不逐人填金額，依總額同額均分。使用者輸入可整除總額，分攤合計須等於支出；無法整除時提示調整金額／參與者並拒絕儲存，不另記尾差。既有編輯仍保留原逐人金額與驗證，相容歷史不同應繳及已收款資料；參與者標題同樣為「實際參與者」。
- 一個收款批次仍是一位團員、同一天、多項行前費用，逐項記實收。新增可複選／全選團員，只列所有選取團員共同參與的費用；各項「每人實收金額」套用到每人，預覽合計乘以人數。
- 多人收款各自建立獨立批次／唯一明細 ID，驗證完成後以一次 batchUpdate 寫入；任一團員或項目失敗時整次不寫入。編輯／刪除仍操作個人批次。已有收款的費用／分攤不能直接刪除，須先處理收款。
- 應繳／實收推導未收、部分已收、已收齊、超收；逐人顯示應繳、實收、未繳及超收，可只看未齊。逐項計算，未繳與超收不能互抵；主要顯示日期、項目與批次合計，批次 ID 限超級使用者。
- 匯率固定「1 TWD＝多少當地幣別」，手動正數；台幣換當地用乘，當地換台幣用除。

### 支出閱讀畫面與參考金額

- 上方統計仍使用整趟實際總額；「整趟參考花費」＝行前台幣實支＋公積金當地實支÷匯率，以 `TWD ` 前綴（後接空格）、千分位及兩位小數顯示，說明不加「；不含公共尾差」。
- 下方卡片依序「所有費用」、再「團員收款摘要」，間距桌面 12px、手機 8px。
- 「所有費用」不顯示日期，依類別分組，類別使用共用 Badge；分類及分類內項目保留首次出現順序。每筆行前費用以實際總額除以該筆實際參與人數、向上取至台幣最小單位，支付方式在金額下方。
- 公積金合併成一筆「公積金支出」，放「其他」類別，與既有同類費用合組。金額為每筆實際消費÷該筆參與人數，各筆先向上取整後加總，代表假設一人全部參加，不取任何團員的最高花費。
- 不顯示「每人全部參加，不含公共尾差」說明，項目與金額整行垂直置中。收款／退款／調整不計入，不重複加上關聯支出；缺少參與者顯示「無法計算」。上述每人參考金額不改寫實際應繳、實收、公積金餘額或上方整趟統計。
- 團員收款摘要：姓名 16px，其餘金額明細 14px，團員 gap 12px，桌面與手機一致。
