# 權限、Google Sheets 寫入、建檔與讀取錯誤

權限與登入、ID 與資料寫入、旅程建檔與 Google 共用、讀取／錯誤／開團進度。

## 權限、登入與公開資料

- 一般團員免登入唯讀及匯出 PDF；指定導遊可編輯。所有真實寫入受 Google Sheets／Drive ACL 強制執行，前端隱藏及 email 比對不能取代授權。
- `VITE_GUIDE_EMAILS` 是 JSON 字串陣列，去空白、轉小寫、去重且保留順序；未設定、空或格式錯誤禁止導遊登入。第一個帳號是唯一超級使用者，其餘是一般管理者；變更順序需重新部署，不轉移 Google 所有權。
- 只有超級使用者可新增／刪除旅程目錄、建立旅程檔案、修改 Spreadsheet 對應、檢查公開讀取及同步導遊編輯權。一般管理者看得到新增旅程按鈕，點擊提示「非管理員：只有超級使用者可新增或刪除旅程」，不開建立表單。
- 一般管理者可編輯其他旅程基本資料及全部旅程內功能；完全移除其試算表設定區塊，儲存保留原 Spreadsheet ID。限制須在流程請求前及實際寫入前重查，不能只藏按鈕。
- 建議旅程目錄只給超級使用者 Google 編輯權，各旅程則授予指定導遊 writer；純前端角色不能阻止有 Google 權限者直接改 Sheets。
- 業務 ID 只在超級使用者畫面顯示，可修改新增時的預設 ID；既有主鍵固定。一般管理者不見 ID 欄、編號提示及關聯選單中的 ID，新增時由儲存流程依最新驗證快照產生，編輯保留原 ID。
- 「查看範例」限登入導遊；範本與設定教學限超級使用者。直接開範例網址仍需登入，登出即停止顯示；範例不得寫入雲端，也不能在真實讀取失敗時自動代替資料。
- 一般瀏覽器用 API Key 直接讀公開 Sheets，Spreadsheet ID 會出現在網路請求中，可據此開啟原始公開試算表，且可讀範圍不限網站欄位。UI 隱藏不構成保密，也不會讓訪客存取其他私人檔案。

### 登入保存

- Google Identity Services OAuth 使用 `VITE_GOOGLE_CLIENT_ID`，以 Google userinfo 驗證已驗證 email 及必要 scope。
- session 存 localStorage，key 按部署 base 區分；保存版本、Client ID、email、access token、原始 expiresAt、scopes。不保存 Client Secret／refresh token，不把 token 放網址。
- 恢復時先驗格式、原有效期、Client ID、指定 email、scope，再用 Authorization header 向 Google 驗證；完成前無導遊權限。非同步結果不得覆蓋較新的登入／登出。
- 不延長 token 效期；到期、Google 驗證失敗或 API 401 清除保存資料，需重登。切回視窗檢查到期；storage 事件同步其他分頁登出／登入，新 session 各自驗證。
- localStorage 不可用時僅保留當次記憶體登入並提示無法保存。SDK 預載失敗不打擾一般訪客，主動登入後才提示與重試。

## ID 與資料寫入

- ID 格式：一個大寫英文字母＋流水號；001～999 補三位，例如 `T001`，之後 `T1000`～`T9999`。超出五字元前再確認擴碼，不默默擴長。
- 取同前綴現有最大號＋1，不以筆數計算、不補缺號。旅程以目錄為範圍，其他以各旅程各表為範圍；關聯只引用來源 ID，不另編號，表單使用選單。
- 前綴：旅程 T、團員 M、公積金交易 F、支出 E、收款明細 R、批次 B、航班 A、住宿 H、行程 I、待辦 P。Google Spreadsheet／OAuth 等外部 ID 不適用。
- 網站、手動 Sheets、範本遵循同一格式與唯一性。讀取錯誤須指出分頁、原始列與欄位；不自動修正雲端不合規 ID 或關聯。
- 旅程目錄以 RAW、按 ID 找列；旅程內以單次 `spreadsheets.batchUpdate`／UpdateCells 的 `userEnteredValue.stringValue` 同步跨表變更，只改有差異的儲存格，必要時同批擴充列／欄。不可將文字當公式。
- 支援換序欄位，保留額外欄、格式及未變更值。刪除只清除該列資料，不移動其他列。團員／航班／住宿被引用時禁止刪除；無法完整確認引用也拒絕。
- 儲存前以導遊授權重新讀取資料及結構，比對編輯快照；不同則拒絕，不宣稱伺服器原子鎖。目錄衝突可保留當次輸入，比較並明確採用最新基準後重試；旅程內衝突須關閉並重新讀取。
- 授權過期、HTTP 拒絕、衝突或儲存結果不明後，重新登入／讀取才可再寫，避免重複記帳；送出前欄位錯誤保留表單供修正。
- 舊表缺少已支援的選填欄位仍可讀，儲存對應資料時於尾端補欄並同批寫入，不搬移舊資料或覆寫額外欄。Excel／範例／Apps Script 同步新結構，不代表已替使用者修改雲端。

## 旅程建檔與 Google 共用

- 新增旅程可按「建立空白旅程試算表」，成功自動填入 ID，也可自行貼網址／ID。新檔放在登入帳號雲端硬碟，含 schema 的十一個旅程分頁、欄位列及必要旅程設定，無示範消費，全部儲存格設純文字。
- 建檔前驗證旅程 ID 格式、目錄唯一性，填入當地幣別、時區、正數匯率；自動寫結構版本、旅程 ID 與設定。建檔成功後旅程 ID 固定。
- 建檔與儲存目錄是兩個動作，按儲存才加入入口；取消、關閉或刪除入口都不刪 Google 檔案。取消後不保留表單建檔進度。
- 建檔順序為格式設定、同步導遊編輯權、公開檢視設定。預設勾選「知道連結的任何人可檢視」，取消則私人；即使私人也要同步導遊編輯權。
- Drive 操作使用 `drive.file`，須啟用 Drive API 並取得新增 scope，不擴大到全 Drive。非本站建立／未授權給應用的舊檔可能需手動共用。
- 同步以全部 env 導遊帳號為目標，但僅作用指定旅程檔案，不自動掃描舊旅程或更動目錄。先查 canShare、讀完整權限分頁，逐筆新增 writer 或提升 reader／commenter，保留更高角色與其他共用權。
- 不轉移所有權、不降權、不建立公開編輯、不寄通知、不隨 env 移除而撤銷既有 Google 權限；完全移除帳號須另外調整 Google 共用。
- 格式／共用部分失敗時，同次表單保留既有檔案 ID 並可續做，重試先讀現況，不重建；建檔結果不明不自動重送。權限逐筆更新，不宣稱原子完成。
- 超級使用者可手動檢查免登入公開讀取與旅程 ID 一致性；私人檔仍可儲存，不自動修改共用。
- 國家搜尋使用隨專案提供的中文／英文／代碼／別名資料，無外部請求；單一幣別／時區自動帶入，多個則選擇，不以首都代替全國。保留手動模式及各模式輸入值。
- 匯率由使用者填；切換國家／幣別時清空舊匯率並提示重填。國家搜尋只輔助填表，不新增國家資料欄。
- 下載提供空白 Excel、完整範例及 Apps Script；目錄範例為 `T001／範例旅程`，示例 Spreadsheet ID 標示待替換。設定教學位於範本說明下方，須反映目前旅程內也可網站編輯。

## 讀取、錯誤與開團進度

- 正常一次批次讀取；因分頁／範圍失敗才分功能讀取。行程、帳務、進度分組驗證，其他組損壞不阻擋有效組；帳務含團員及全部帳務表，共同核對。共用旅程設定錯誤阻擋整趟。
- 目錄錯誤列不阻擋其他有效旅程；寫入仍嚴格驗證。錯誤不可當空白覆寫或顯示有效零金額；讀取更新時清除舊內容，成功才顯示新資料，權限拒絕不得保留舊資料。
- 一般團員只見簡短錯誤及「請稍後再試，或聯絡導遊」，不提 Sheets／共用／技術細節；導遊可看分頁、原始列、欄位與資料位置連結。列號不受空白列影響。
- 明確檔案權限不足時保留目錄的旅程名稱、目的地及日期，顯示「此旅程暫不開放觀看」與重試／聯絡導遊，不顯示旅程內容及選單。導遊另見公開共用指引。
- 以訪客免登入讀取判斷公開狀態，不用導遊 token 讀私人內容。403 本身、API Key 限制、配額、網路、404 等不能直接宣稱未共用；重新開放可重讀，不長期快取此狀態。
- 入口支援名稱／目的地搜尋及進行中／已結束篩選，進行中包含所有非已結束狀態。
- 旅程總覽不顯示舊範本的「請填入旅程 ID、當地幣別與匯率（1 台幣 = 多少當地幣）。」建檔提示；自訂旅程說明仍正常顯示。Apps Script 新建範本的旅程說明留空，不將設定教學寫成旅程內容。
- 總覽列最早截止的三項未完成待辦；7 天內到期含今天至七天後，排除完成／取消，逾期另標示。依旅程時區，每分鐘及視窗恢復時更新日期；日期／待辦篩選保留 aria-pressed。
