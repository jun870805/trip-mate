# AI 助手右側介面與對話保存

狀態：使用者已核准 `sketches/ai-sidebar` 版本並實作於正式旅程頁面。預覽服務已關閉；樣稿檔保留供對照，現行規格同步於 AGENTS.md。

## 已採用介面

- 右下機器人入口：32px 圖示、72px 寬點擊區；入口文字固定「AI 助手」，有待確認操作時另顯示「待確認」，不閃爍。手機避開底部導覽。
- 701px 起為頂到視窗上緣／底部的右側非模態側欄，Logo／header 與內容一同讓出寬度；寬螢幕 408px，701～1120px 依寬度調整至 300～376px。左側讓出空間，可捲動、切日期／標籤並直接展開行程內文。聊天訊息獨立捲動，不帶動左側。
- 700px 以下為接近滿版的聊天窗，單一元件跨 breakpoint 保留 agent、輸入與附件。以 modal 語意、背景 inert、焦點循環及既有共用捲動鎖限制背景。
- 標題「AI 助手」，Header 使用共用無邊框 X（保留縮小行為），Escape 同樣縮小。X 左側有邊框「新對話」文字按鈕，點擊清空當前對話與上下文後重新開始，移除記錄、上下文、草稿、附件、未提交預覽及暫存；不撤銷已儲存行程或刪除供應商已接收內容。寫入中縮小／清空停用。

## 無後端的重新整理保存

使用 sessionStorage 保存本分頁已完成且無附件的對話；重新整理後開啟助手可恢復。關閉分頁後不保證保留，沒有跨裝置同步。

- 核心 `exportConversation()`／`restoreConversation()` 提供版本化 checkpoint；Host 注入儲存，核心不直接依賴瀏覽器或 env。
- 同時保存畫面與下一次模型請求的完整歷史，包括配對工具結果與 Provider opaque／簽章；不只還原泡泡。不恢復權限、閉包或執行工具。
- 按部署 base、來源、旅程／Spreadsheet、身份、Firebase 設定與模型隔離。登入身份離開時清除舊身份資料；重新整理的登入驗證不誤刪驗證中身份的紀錄。不保存 OAuth token。
- 只保存穩定完成節點；未送出輸入、附件原文、待確認與正在寫入的動作不保存。附件參與後整段對話只留當次記憶體，介面明示，重新整理後須重新上傳。
- 等待批准／處理中只保留之前已完成紀錄；開始寫入或發生錯誤即移除暫存，不重播或自動重試。
- 嚴格驗證版本、範圍、格式、角色、工具配對及完成狀態，最多 80 則／1 MiB；錯誤或模型設定不同時不恢復。儲存不可用／額滿時回退記憶體並提示；歷史仍受核心 token／請求大小限制。
- 左側手動更新使舊 agent／預覽失效，新的對話可恢復已完成 checkpoint；每次工具讀取與批准仍使用目前資料與授權。單純看日期／捲動不清除聊天。

實作入口：`frontend/src/features/trip-ai/TripAIEntry.tsx`、`useChatSurface.ts`、`conversation-storage.ts`；可移植契約與限制見 `frontend/src/ai/README.md`。
