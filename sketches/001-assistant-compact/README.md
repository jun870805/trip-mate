# 精簡圖示

## Design stance
一般狀態只留圖示，有對話或待確認內容時才展開文字。

## Key choices
- 圖示：手繪 SVG 線條，沿用既有 1.6px 筆畫與奶茶棕。
- 顯示：桌面右下聊天視窗；手機接近滿版。
- 字體／配色：既有 Microsoft JhengHei、米白與奶茶棕；4px／8px 圓角。
- 互動：開啟、縮小保留、X／Escape 清除，待確認只顯示狀態，不自動提交。

## Trade-offs
遮擋較少；初次使用的辨識度較低。

## Best for
已熟悉 AI 功能且希望少遮擋行程的使用者。

配色已內嵌在 HTML 中，可獨立開啟；亦可透過本機預覽網址操作。

所有資料與回覆均為明確標示的介面範例；不呼叫 AI、Google API 或儲存資料。
