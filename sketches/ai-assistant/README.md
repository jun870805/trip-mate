# AI 助手入口設計比較

建議從專案根目錄執行 `python3 scripts/preview_ai_sketches.py`，再用瀏覽器開啟 `http://127.0.0.1:5196/ai-assistant/`。可切換一般、縮小及待確認狀態。比較頁已內嵌完整樣稿與配色，不依賴其他 HTML／CSS 檔案載入；單獨方案也可直接開啟。

對話附件／圖片檢視器可能不執行 JavaScript，互動測試請在實際瀏覽器中開啟上述網址。服務只綁定 127.0.0.1 並提供 sketches 資料夾，沒有資料 API。

建議採 A 常駐文字：AI 助手容易辨識、操作目標至少 48px，縮小後顯示「繼續對話」，待確認顯示明確文字而非未讀紅點。
