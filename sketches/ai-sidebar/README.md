# AI 助手右側欄與手機聊天窗預覽

狀態：僅供確認畫面與操作的獨立樣稿，尚未套用正式網站。未呼叫模型、Google API 或改動旅程資料。

## 開啟

從專案根目錄執行 `python3 scripts/preview_ai_sketches.py`，再開啟 `http://127.0.0.1:5196/ai-sidebar/`。上方可切換電腦與手機預覽；`prototype.html` 可單獨開啟。比較頁內嵌完整樣稿，不依賴分開載入 CSS／JS。

## 主要選擇

- 沿用專案米白、奶茶棕、Microsoft JhengHei 與 4px／8px 圓角。
- 機器人按鈕 64×72px，圖示 32px；展開後 header 保留明確機器人標識，只有縮小操作，沒有 X。
- 桌面寬度充足時為約 408px 右側欄，左側預留空間、兩區獨立捲動；窄視窗改成聊天視窗。
- 左側可切換日期、展開行程詳情，同時保持聊天可操作。詳情使用左側內嵌展開，讓使用者能直接比較這種同時查看的體驗。
- 手機聊天窗避開安全區，開啟時鎖住背景操作；縮小後的機器人入口避開底部導覽。
- 清空對話移除樣稿訊息、示範上下文、輸入、附件及待確認內容，不修改旅程。

## 可以試的互動

1. 在右側點「第二天有哪些行程？」，再切換左側 D2、點「查看更多」。
2. 輸入一些文字，縮小再開啟：未送出文字仍在。
3. 送出對話，再按上方「重新整理預覽」：已完成對話仍在，未送出文字不保留。
4. 送出「你記得我剛剛問什麼嗎？」：只示範樣稿如何接續已保存的文字。
5. 按「清空對話」，再重新整理：舊樣稿紀錄不會恢復。
6. 點「調整第二天時間」查看待確認狀態；確認只改樣稿畫面，不呼叫資料服務。未確認內容不跨重新整理保存。
7. 切換上方手機版，試縮小、恢復與清空；上傳按鈕只展示範例附件，不讀取或上傳本機檔案。

## 保存範圍

樣稿的文字紀錄存於獨立 `sessionStorage` key：`trip-mate:sketch:ai-sidebar:v1`，最多 40 則。這只是預覽的本機互動，正式 Agent 的上下文匯出／還原尚未實作，也不宣稱具備真實 AI 記憶。儲存不可用時回退記憶體。
